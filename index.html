● COMMUNITY SUPPORT GUIDE

遇到 Bug？
这样提交反馈。

清楚的复现步骤、正确的系统信息和运行日志，能帮助开发者更快定位问题。按下面的步骤整理后，在 GitHub 提交 Issue。

01 / 出问题后，先保存日志

1

打开游戏所在文件夹

找到 totk.exe 所在的位置，进入里面的 logs 文件夹。

游戏目录 / logs / totk.log
2

找到最近一次运行的日志

通常提交 totk.log。如果出问题后又重新启动过游戏，旧日志可能会变成 totk.1.log，请选出问题那次运行对应的文件。

重要：崩溃或异常发生后，尽量先复制日志，再重新启动游戏。重新启动可能会轮换日志文件。
3

如果是安装失败

请附上安装器日志，包括文件名以 install 开头的 .log，以及 lift-gen.log（如果存在）。

02 / 收集版本和设备信息

1

记录两个版本号

启动游戏后按 F1 打开设置菜单，在菜单标题栏查看 TotK Recomp 版本和游戏更新版本。

2

复制系统信息

在设置菜单进入 Advanced 页面，点击 Copy system info，把复制的内容粘贴到 Issue 中。里面包含显卡型号、驱动版本等开发者需要的信息。

3

准备复现步骤

按顺序写清楚做了什么、在哪里发生、预期结果是什么、实际发生了什么。若有帮助，可以附截图。

通常不需要录制很长的游戏视频。

03 / 在 GitHub 提交 Bug

打开项目 Issues 页面，选择新建 Issue，并使用 Bug 报告模板填写。把日志文件拖入编辑框作为附件。

打开 GitHub Issues ↗大陆访问加速入口 ↗

加速入口由第三方提供，可能不稳定；能直连时优先使用 GitHub 原地址。

反馈内容参考

可按这个结构整理信息。GitHub 页面若提供专用 Bug 模板，请优先按页面中的字段填写。

### Description 简要描述遇到的问题。 ### Steps to Reproduce 1. 2. 3. ### Expected Behavior 描述原本预期发生什么。 ### Actual Behavior 描述实际发生了什么。 ### Version Information - TotK Recomp version: - Game update version: ### System Information 请粘贴设置菜单 Advanced 页面中 Copy system info 复制的完整内容。 ### Logs 请附上出问题那次运行对应的 totk.log。 若为安装失败，请附 install*.log 和 lift-gen.log（如有）。 ### Additional Information 可补充截图、发生频率，以及最近是否更改过设置。

提交前，先看看已知问题

如果问题已经有人报告，先查看现有讨论，必要时在对应 Issue 中补充自己的版本、设备信息和日志，避免重复开帖。

查看项目已知问题汇总 ↗

提交时请注意

  • 尽量提供完整日志，不要只截取最后几行。
  • 描述问题时写清楚复现步骤，不确定原因也没关系，不需要猜测。
  • 不要上传游戏本体、固件、密钥、提取的游戏资源或其他受版权保护的游戏文件。
  • 不要上传编译二进制、shader、shader cache、字体、音频或视频等游戏内容。
  • 截图可以帮助说明问题，但请留意不要包含个人隐私信息。
